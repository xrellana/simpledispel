# SimpleDispel

A minimal click-to-dispel addon for World of Warcraft Retail 12.1+.

The project is currently in the API validation stage. Development scope,
milestones, test gates, and the policy for WoW 12.1 API limitations are defined
in [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).

The current `player`/`party1` prototype can be tested by following
[STAGE1_TESTING.md](STAGE1_TESTING.md).
