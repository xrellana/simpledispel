# SimpleDispel branding assets

These files are original vector artwork for the SimpleDispel project.

| File | Intended use |
|---|---|
| `simpledispel-avatar.svg` | Primary square project avatar and source for the CurseForge PNG |
| `simpledispel-avatar-flat.svg` | Simpler square avatar for very small sizes or flatter UI |
| `simpledispel-wordmark.svg` | Horizontal project header, README, or social preview |
| `simpledispel-mark-mono.svg` | Single-color transparent mark for dark backgrounds |
| `simpledispel-avatar-1024.png` | Recommended CurseForge upload, already exported at 1024 × 1024 |
| `simpledispel-avatar-flat-1024.png` | Alternate CurseForge upload with fewer visual details |
| `simpledispel-wordmark-1600.png` | Raster export of the horizontal wordmark |

## Visual idea

- The shield represents the fixed, secure unit button.
- The purple tile represents a harmful aura.
- The mint sparkle represents dispelling the aura.
- The pointer makes the addon's click-to-dispel interaction explicit.
- Mint `#4EE6A8` comes from the addon's existing chat prefix in `Core.lua`.

## CurseForge export

CurseForge requires a square PNG project avatar rather than an SVG upload. Export
`simpledispel-avatar.svg` at 1024 × 1024 pixels as
`simpledispel-avatar-1024.png`. Keep the SVG as the editable master.

Do not add the World of Warcraft, Blizzard, or CurseForge logo to the artwork.
The project mark is intentionally original and does not include game artwork.
